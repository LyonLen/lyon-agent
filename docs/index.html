#快速开始

一个 Go 守护进程 + 一个前端 dev server，浏览器即工作台。

1 · 构建

# 仓库根目录（需要 Go ≥ 1.25）
go build -o bin/lyond  ./cmd/lyond    # 守护进程：会话 / 工具 / 审批 / 网关

# 前端（dev server 热更新；生产构建用 npm run build）
$ cd web && npm install && npm run dev   # → http://localhost:5183

2 · 配置凭证

# Anthropic 官方
$ export ANTHROPIC_AUTH_TOKEN=sk-ant-...

# 或任意 OpenAI 兼容端点（key 与 base URL 一并配置）
$ export ANTHROPIC_BASE_URL=https://token-plan-cn.xiaomimimo.com/v1
$ export ANTHROPIC_AUTH_TOKEN=<your-key>

3 · 启动

$ ./bin/lyond -addr 127.0.0.1:8080 -workspace .   # 守护进程（前端 dev server 默认代理到 8080）
$ 打开 http://localhost:5183                        # 浏览器就是工作台
数据都在本地：会话、榜单、考核记录、记忆全部存在 $LYON_HOME（默认 ~/.lyon）。 无遥测；记忆云同步默认关闭，显式配置 LYON_SYNC_URL/TOKEN 后才启用，且仅团队/个人层参与，项目层永不离开本机。

#从这里开始学

新用户建议按顺序读——每一章都能独立上手。

  1. 快速上手 构建 lyond 与 web、凭证、第一次打开工作台。
  2. 界面导览 侧栏、聊天区、平铺面板、底栏各干什么。
  3. 交互指南 键位、命令面板、审批卡片、面板手势——全部以 web 实际行为为准。
  4. 演化机制详解 评分 → 考核 → 路由 → 覆盖门禁 → workflow 冻结，五级火箭怎么串起来。
  5. 配置参考 lyond 启动标志、环境变量一张表查清。
