#快速开始

零依赖（Go ≥ 1.25 编译即可跑），Anthropic 与 OpenAI 兼容端点都支持。

1 · 构建

# 仓库根目录
go build -o bin/lyon   ./cmd/lyon      # 终端主程序（CLI + 全屏 TUI）
go build -o bin/lyond  ./cmd/lyond     # OpenAI 兼容网关（可选）

2 · 配置凭证

# Anthropic 官方
$ export ANTHROPIC_AUTH_TOKEN=sk-ant-...

# 或任意 OpenAI 兼容端点（key 与 base URL 二选一配置即可）
$ export ANTHROPIC_BASE_URL=https://token-plan-cn.xiaomimimo.com/v1
$ export ANTHROPIC_AUTH_TOKEN=<your-key>

3 · 启动

$ ./bin/lyon chat            # 全屏 TUI 工作台
$ ./bin/lyon -p "重构这个函数"  # 单次 CLI 执行，打完即走
$ ./bin/lyon chat            # 会话自动落盘，/resume 随时续上
数据都在本地：会话、榜单、考核记录全部存在 $LYON_HOME（默认 ~/.lyon）。 无遥测、无云同步。

#从这里开始学

新用户建议按顺序读——每一章都能独立上手。

  1. 快速上手 构建、凭证、第一次对话；TUI 按键与斜杠指令速查。
  2. 界面导览 四个区域各干什么：转录区、输入区、临时输出区、步骤审计面板。
  3. 演化机制详解 评分 → 考核 → 路由 → 覆盖门禁 → workflow 冻结，五级火箭怎么串起来。
  4. 命令与配置参考 全部斜杠指令、启动标志、环境变量一张表查清。
  5. 常见问题 迭代预算为什么会停、resume 恢复了什么、门禁会不会卡死……
